# 한입 타로 서비스 기획서

- 작성일: 2026-09-29
- 대상 서비스: 타로타르트
- 상태: 기획 검토 초안. 이 문서는 기능 구현·운영 정책 확정·배포를 의미하지 않는다.
- 한 줄 소개: **끌리는 카드 하나, 짧고 선명한 답.**

## 1. 기획 배경과 목표

현재 타로타르트에는 질문을 입력하는 한 장·세 장·다섯 장 타로, 질문 없는 오늘의 타로와 월별 타로가 있다. 한입 타로는 질문을 직접 작성하거나 긴 해석을 읽을 여유가 없는 사람에게, 쇼츠·릴스처럼 짧게 참여하고 답을 확인하는 경험을 제공한다.

사용자는 자신의 고민과 닿는 주제를 발견하고 카드 하나를 선택한다. 결과는 결론 한 줄과 이유 두 줄로 읽는다. 한 콘텐츠를 선택하고 읽는 데 **10~20초가 걸리는 경험을 설계 목표**로 삼는다. 이는 아직 측정되지 않은 목표이며, 읽는 속도를 제한하는 타이머는 두지 않는다.

### 지금까지 합의한 방향

- 쇼츠·릴스처럼 빠르게 보는 타로 경험을 지향한다.
- 미리 제시된 주제에서 끌리는 카드 하나를 고르는 픽어카드 방식을 사용한다.
- 짧아도 질문에 대한 답의 방향과 카드에 근거한 이유가 있어야 한다.
- 수집·취미의 즐거움을 인정하며, 욕구를 곧바로 집착으로 해석하지 않는다.
- 행동에 대한 권고와 미래 결과의 보장을 구분한다.

### 이 문서에서 제안하는 기본값

서비스 이름, 화면 구성, 출시 콘텐츠 수, 사전 제작 방식, 무료 제공 및 재선택 정책은 아래의 제안값이다. 구현 전에 이 기획서를 검토해 확정한다.

## 2. 콘텐츠의 정체성

픽어카드(Pick a Card)는 카드 또는 카드 묶음을 선택한 뒤 해당 해석을 확인하는 온라인 리딩 형식이다. 반드시 짧거나 한 장만 사용하는 형식은 아니다. 한입 타로는 이를 **주제별 한 장 해석과 짧은 화면 흐름**으로 구성하는 서비스다.

첫 이용 때 다음 설명을 짧게 제공한다.

> 모두에게 열린 주제로 보는 타로예요. 끌리는 카드 하나를 고르면 그 카드의 짧은 조언을 보여드려요.

이용자가 입력하지 않은 개인 상황을 분석한 것처럼 표현하지 않는다. 카드 선택은 실제로 제시된 해석을 결정하며, 어떤 카드를 눌러도 같은 답을 보여주는 연출은 사용하지 않는다.

| 구분 | 사용자의 시작점 | 얻는 것 |
|---|---|---|
| 한입 타로 | 눈에 들어온 주제 | 짧은 권고와 이유, 다음 주제 탐색 |
| 오늘의 타로 | 오늘 하루가 궁금함 | 하루의 테마와 일상 행동 |
| 한 장 타로 | 직접 작성한 고민 | 개인 질문에 연결한 해석과 실천 조언 |
| 세 장·다섯 장 타로 | 더 살펴보고 싶은 고민 | 여러 자리의 의미를 연결한 설명 |
| 월별 타로 | 앞으로의 월별 흐름이 궁금함 | 월별 주제와 분야별 조언 |

한입 타로의 핵심 가치는 특정 상황에 정밀하게 맞춘 상담보다 **진입의 편리함, 선택의 재미, 빠른 이해**에 있다.

## 3. 대상 사용자와 이용 장면

- 잠깐 쉬는 시간에 가볍게 무언가 보고 싶은 사람.
- 타로가 궁금하지만 질문을 길게 작성하는 것은 부담스러운 사람.
- 작은 선택을 앞두고 다른 관점을 짧게 얻고 싶은 사람.
- 친구가 공유한 특정 주제를 바로 열어보고 싶은 사람.

중요한 계약, 투자 종목, 의료·법률 판단 등을 짧은 추천 카드로 결정하게 만드는 콘텐츠는 첫 출시 범위에서 제외한다. 로또·도박, 당첨 번호·확률, 상대의 속마음이나 배신을 알아맞히는 주제도 제외한다. 이는 기존 상담 전체의 정책 변경이 아닌 한입 타로의 편집 범위다.

## 4. 진입과 핵심 이용 흐름

### 홈 진입

기존 주문서의 **‘가볍게 한 입’** 영역에 ‘오늘의 타로’와 별도로 **‘한입 타로’** 메뉴를 추가한다.

- 메뉴 이름: 한입 타로
- 보조 설명: 주제를 고르고, 카드 하나로 짧게
- 메뉴 선택 후 기존 캐릭터 주문 스탬프로 진입한다.
- 콘텐츠 공유 링크로 들어온 사람은 홈 주문 단계를 거치지 않고 해당 주제부터 본다.

### 콘텐츠 안의 흐름

1. 첫 화면에 주제 한 개와 뒤집힌 카드 3장을 보여준다.
2. 사용자는 끌리는 카드 하나를 누른다.
3. 선택한 카드가 뒤집히며 카드 이름, 결론, 이유가 같은 화면 안에 나타난다.
4. 위로 넘기거나 ‘다음 주제’ 버튼을 눌러 다음 콘텐츠로 이동한다.
5. 아래로 넘기거나 ‘이전 주제’ 버튼을 누르면 앞서 본 결과를 그대로 확인한다.

질문 입력, 별도의 주제 카테고리 선택, 전체 78장 탐색, 긴 셔플은 이 흐름에 넣지 않는다. 카드를 고르기 전에도 다음 주제로 넘어갈 수 있다. 한 번의 스와이프는 한 주제만 이동하며 자동으로 다음 콘텐츠를 재생하지 않는다.

초기 콘텐츠를 모두 본 뒤에는 ‘준비된 한입을 모두 봤어요’와 ‘주제 다시 보기’를 제공한다. 같은 주제를 끝없이 새로운 콘텐츠처럼 반복하지 않는다.

## 5. 화면 구성

### 선택 전

```text
한입 타로                         2 / 12

그 물건, 살까 말까?
지금 고민하는 물건을 떠올려보세요.

       [카드 1] [카드 2] [카드 3]

        끌리는 카드 하나를 골라주세요

                    다음 주제 ↓
```

### 선택 후 — 태양 카드의 예시

```text
그 물건, 살까 말까?

                 [태양]

        사는 쪽을 추천해요.

태양의 기쁨을 취향을 누리는 이유로 읽었어요.
꼭 실용적이지 않아도 수집의 즐거움은 가치 있어요.

        [주제 공유]    [내 고민으로 더 보기]

                    다음 주제 ↓
```

위 예시는 문장 길이와 표현 방향을 설명하기 위한 것으로, 전체 콘텐츠를 이 문장에 맞춰 반복 생성하지 않는다.

### 시각·접근성 기준

- 세로 화면 한 장에 한 주제를 배치해 짧은 콘텐츠의 리듬을 만든다.
- 카드 공개 동작은 약 0.4~0.7초를 제안한다. 불필요한 대기나 강제 카운트다운은 없다.
- 결과의 시각적 우선순위는 결론 → 카드와 이름 → 이유 → 보조 버튼이다.
- 최소 너비 280px에서 카드·버튼·글자가 겹치지 않는다. 작은 화면과 글자 확대에서는 본문 스크롤을 허용한다.
- 본문을 스크롤하는 동작이 곧바로 다음 주제로 넘어가지 않도록 구분한다.
- 스와이프 외에 버튼과 키보드로도 이동·선택할 수 있게 한다.
- 동작 줄이기 설정에서는 뒤집기·화면 전환을 단순화한다. 소리나 자동 음성 재생은 넣지 않는다.

## 6. 출시 콘텐츠 구성

첫 출시에는 **12개 주제 × 선택지 3개 = 해석 36개**를 제안한다. 정방향 카드만 사용한다. 사용자가 고르는 것은 세 장 전체의 해석이 아니라 세 선택지 중 한 장의 해석이다.

| 영역 | 주제 제목 | 콘텐츠가 답할 범위 |
|---|---|---|
| 작은 선택 | 그 물건, 살까 말까? | 소장의 즐거움과 구매 판단 |
| 작은 선택 | 오늘 새로운 취미를 시작할까? | 첫 시도에 대한 권고 |
| 작은 선택 | 오늘은 계획대로 할까, 여유를 둘까? | 일상 속 속도 조절 |
| 관계 행동 | 내가 먼저 안부를 전할까? | 연락 여부와 부담 적은 방식 |
| 관계 행동 | 친구에게 서운한 마음을 말할까? | 감정을 전하는 시점과 방법 |
| 관계 행동 | 함께 점심 먹자고 해볼까? | 가벼운 제안과 상대 선택 존중 |
| 시작과 집중 | 미뤄둔 작은 일을 오늘 시작할까? | 실행 여부와 첫걸음 |
| 시작과 집중 | 내 아이디어를 먼저 꺼내볼까? | 표현과 준비의 균형 |
| 시작과 집중 | 막힌 작업, 계속할까 잠깐 쉴까? | 일상적 작업의 진행·휴식 |
| 마음 정리 | 지금 내 마음에 필요한 한마디는? | 카드 상징으로 보는 관점 |
| 마음 정리 | 오늘은 무엇을 덜 신경 써도 될까? | 통제 가능한 일과 내려놓을 일 |
| 마음 정리 | 나에게 작은 보상을 줘도 될까? | 자기 돌봄과 즐거움의 인정 |

다른 주제를 연속으로 볼 수 있게 순서를 구성하고, 같은 영역이 지나치게 이어지지 않게 한다. 첫 출시에는 개인 행동을 분석하는 추천 알고리즘 없이 편집된 순서를 사용한다.

## 7. 카드 선정과 결과 작성 원칙

### 선택지 구성

- 주제마다 서로 다른 카드 3장을 편집자가 선정한다. 카드와 해석은 함께 검수한다.
- 78장을 모두 무작위로 뽑는 기존 한 장 타로와 달리, 이번 서비스는 주제별로 준비된 세 선택지를 고르는 방식이다.
- 선택지는 주제에 맞는 의미 차이가 있어야 하지만, 반드시 YES·NO·보류를 한 개씩 맞추지는 않는다.
- 카드 위치는 첫 진입 때 섞고 해당 주제를 보는 동안 고정한다. 카드와 해석의 연결은 바뀌지 않는다.
- 예: 구매 주제에서 태양은 즐거움의 가치, 매달린 사람은 관점 전환과 잠시 멈춤, 펜타클 4는 자원을 지키는 기준으로 읽을 수 있다. 정확한 결론은 주제와 카드 의미를 함께 검토해 정한다.

### 결과 형식

- 카드: 실제 카드 이미지와 이름.
- 결론: 한 문장, 권장 15~45자.
- 이유: 두 문장, 합계 권장 50~110자. 화면에서는 기기 너비에 따라 줄바꿈한다.
- 선택 질문: 진행 추천·보류·비추천 중 읽히는 방향을 자연스럽게 먼저 말한다.
- 마음 정리 질문: 핵심 메시지부터 답하며 YES/NO를 억지로 붙이지 않는다.
- 별도의 긴 조언, 운세 점수, 성공 확률, 성찰 질문 목록은 넣지 않는다.

### 편집 기준

1. 결론만 읽어도 질문에 대한 방향을 알 수 있어야 한다.
2. 이유에는 왜 그 카드로 그렇게 읽었는지 담는다. 카드 이름을 바꿔도 똑같이 성립하는 문장을 피한다.
3. 카드에 없는 장면이나 사용자가 말하지 않은 사정을 만들어내지 않는다.
4. 조건은 권고를 바꿀 만큼 중요한 경우에만 짧게 덧붙인다. 모든 구매를 ‘예산을 확인하세요’로 끝내지 않는다.
5. 갖고 싶다는 마음과 거절하기 어려운 압박을 구분한다. 욕구 자체를 잘못으로 다루지 않는다.
6. ‘권해요’와 ‘그렇게 될 거예요’를 구분한다. ‘후회가 없어요’, ‘상대도 기다리고 있어요’처럼 결과나 속마음을 보장하지 않는다.
7. 같은 질문을 다른 방식으로 보면 무조건 더 정확해진다는 인상을 주지 않는다.
8. 따뜻한 구어체를 사용하고, 과도한 경고·면책 문구가 결론을 덮지 않게 한다.

화면 하단에는 ‘카드의 상징으로 읽는 짧은 조언이에요’라는 공통 보조 문구를 제공한다. 이 문구와 별개로 각 콘텐츠 자체가 위 원칙을 지켜야 한다.

## 8. 속도와 콘텐츠 운영

### 제안: 미리 제작하고 검수한 해석 제공

현재 질문형 리딩은 실제 요청 때 AI가 해석을 생성한다. 한입 타로는 빠른 공개가 핵심이므로 **선택 순간의 AI 생성 대신 사전에 준비한 해석**을 제공하는 방식을 권장한다.

- 초안 작성에는 현재 카드 기본 설명과 AI를 활용할 수 있다.
- 공개 전 사람이 카드와 문장의 대응, 결론, 단정 표현, 오탈자를 검수한다.
- 공개된 버전에서는 같은 주제의 같은 카드가 같은 해석을 제공한다.
- 선택 시 네트워크 생성 대기가 없도록 해당 주제의 카드·해석을 미리 준비한다. 첫 페이지 로딩까지 항상 즉시 완료된다는 의미는 아니다.
- 초기 콘텐츠 36개는 버전 관리되는 데이터 파일로 운영하고 별도 관리 화면은 만들지 않는다.

실시간 AI는 개인 질문을 반영할 수 있지만 이번 흐름에는 개인 질문 입력이 없고 응답 대기가 생긴다. 따라서 개인화는 기존 상담으로 이어지는 단계에 맡긴다.

### 최소 콘텐츠 정보

주제 ID, 버전, 제목, 안내 문장, 카테고리, 노출 순서, 공개 상태, 카드별 ID·결론·이유·검수 완료 여부를 보관한다. 카드 ID는 기존 78장 체계를 재사용한다.

새 콘텐츠는 초안 → 카드 의미 검토 → 문장·모바일 길이 검수 → 공개 순서로 운영한다. 출시 후 업데이트 주기는 제작 부담과 이용 반응을 본 뒤 정하며, 처음부터 매일 새 콘텐츠를 약속하지 않는다.

## 9. 다시 보기·공유·상담 연결

### 재선택과 보관

- 처음 고른 카드만 공개하며, 같은 주제에서 나머지 카드를 연속으로 뒤집는 기능은 제공하지 않는다.
- 같은 브라우저에서는 주제 ID와 콘텐츠 버전별로 선택·결과를 보관한다. 새로고침하거나 앞뒤로 이동해도 같은 결과를 보여준다.
- 초기 저장은 기기 내부에서만 처리하고 계정 간 동기화나 상담 기록 자동 저장은 제공하지 않는다.
- 저장이 불가능한 환경에서는 현재 화면을 이용하는 동안만 유지한다. 저장 실패 때문에 카드 이용을 막지 않는다.
- 브라우저 데이터 삭제·다른 기기 이용·새 콘텐츠 버전에서는 다시 선택할 수 있다. 이 정책은 강한 이용 횟수 제한을 보장하는 방식이 아니다.

### 공유

- 초기에는 이미지 제작보다 주제 링크 공유를 제공한다.
- 공유받은 사람은 해당 주제를 열어 직접 카드를 선택한다. 보낸 사람의 선택 결과를 강제로 보여주지 않는다.
- 콘텐츠 버전이 변경되면 현재 버전으로 안내하고, 삭제된 주제라면 이용 가능한 목록으로 돌아갈 수 있게 한다.
- 공유 API를 사용할 수 없으면 링크 복사를 제공한다.
- 공유·좋아요·댓글을 해야 결과가 공개되는 조건은 두지 않는다.

### 내 고민으로 더 보기

- 결과 하단의 작은 보조 버튼으로 기존 한 장 타로의 질문 작성 화면에 연결한다.
- 해당 주제를 질문 초안으로 전달하되 사용자가 자신의 상황에 맞게 고칠 수 있게 한다.
- 별도의 개인 상담이 시작된다는 점과 기존 시트 이용 조건을 그 흐름에서 안내한다. 버튼을 누르는 즉시 시트를 차감하지 않는다.
- 한입 결과를 더 좋은 답으로 뒤집거나 확증하기 위한 재추첨처럼 표현하지 않는다.

## 10. 이용 정책과 수익화 제안

첫 출시는 **로그인 없이 무료, 한입 타로 자체의 시트 차감 없음**을 제안한다. 결과 공개 전 광고나 결제 단계는 넣지 않는다.

목표는 먼저 짧은 경험이 실제로 잘 소비되는지 확인하는 것이다. 기존 유료·무료 시트 정책을 바꾸지 않고, 추가 개인 상담에 진입한 경우 기존 정책을 따른다. 광고·테마팩·유료 구독 등 새로운 수익화는 초기 범위에서 제외한다.

## 11. 첫 출시 범위

### 포함

- ‘가볍게 한 입’ 메뉴에 진입점 추가.
- 12개 주제와 검수된 해석 36개.
- 세 카드 중 하나 선택, 같은 화면에서 짧은 결과 공개.
- 주제별 세로 이동과 이전·다음 버튼.
- 기기 내 선택 유지, 주제 링크 공유, 개인 상담으로 연결.
- 작은 화면·키보드·동작 줄이기 설정 대응.

### 후속 검토

- 결과 이미지 저장과 쇼츠·릴스 영상 내보내기.
- 음성 리딩, 배경 음악, 댓글·좋아요.
- 개인화 추천, 계정 간 동기화, 콘텐츠 관리 화면.
- 여러 장으로 구성한 선택 묶음, 역방향 카드.

초기에는 영상을 제작·재생하는 기능 없이도 주제 단위의 짧은 탐색과 카드 공개로 쇼츠에 가까운 경험을 제공한다.

## 12. 확인할 지표와 출시 기준

### 확인할 지표

| 질문 | 지표 정의 |
|---|---|
| 쉽게 참여하는가? | 주제가 보인 이용 중 카드 선택으로 이어진 비율 |
| 충분히 빠른가? | 주제 노출부터 선택까지 걸린 시간, 선택부터 결과 표시까지 걸린 시간 |
| 짧게 읽히는가? | 결과 노출부터 다음 이동까지 시간과 간단한 사용성 관찰을 함께 확인 |
| 다른 주제도 보는가? | 방문당 고유 주제 열람 수, 두 번째 주제의 카드 선택 비율 |
| 상담으로 이어지는가? | 결과를 본 이용 중 개인 상담 진입 비율 |
| 공유할 이유가 있는가? | 결과를 본 이용 중 주제 공유 기능 사용 비율 |

오래 머무는 것이 항상 좋은 결과는 아니다. 읽기 어려워 머무는 경우와 즐겨서 탐색하는 경우를 구분한다. 수치 목표는 초기 관찰 후 설정하며, 위 지표가 현재 수집되고 있다는 뜻은 아니다.

계측을 추가한다면 주제 ID·버전·화면 단계 등 최소 이벤트를 사용한다. 질문 원문·개인 상담 내용은 포함하지 않고 기존 분석 도구와 개인정보 안내 범위를 구현 때 확인한다.

### 출시 전 최소 확인

- 36개 해석의 카드 의미, 결론·이유 일치, 단정 표현과 길이를 콘텐츠 검수로 확인한다.
- 선택한 카드와 해석이 맞고, 재진입해도 결과가 바뀌지 않는지 관련 동작만 확인한다.
- 모바일에서 선택 → 결과 → 다음 주제 → 이전 결과 복원 흐름을 확인한다.
- 공유 링크, 삭제된 주제, 저장 불가 환경, 마지막 주제의 종료 상태를 확인한다.
- 개인 상담 연결이 기존 질문·시트 흐름을 우회하지 않는지 확인한다.
- 관련 타입 검사와 필요한 소수의 동작 검사만 수행한다. 무관한 전체 기능 검사나 과한 AI 반복 호출은 하지 않는다.
