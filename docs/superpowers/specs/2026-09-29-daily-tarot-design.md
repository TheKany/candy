# 오늘의 타로

## 목적과 범위

질문 없이 가볍게 하루의 방향을 읽는 메뉴다. 이미 승인된 캐릭터와 `카드 | 에너지 % → 절취선 → 해석` 구성을 사용한다. 워터마크는 별도 배포 완료했으나, 추가 요청에 따라 배경에서는 제거하고 ‘가볍게 한 입’ 주문서 우측 상단 스탬프에 캐릭터를 사용한다. 사용자가 전체 구현과 배포를 승인했다.

## 사용자 흐름

1. 주문서의 ‘가볍게 한 입’에서 ‘오늘의 타로’를 선택한다. 선택 체크 후 캐릭터 스탬프가 활성화되고 원 테두리를 따라 ‘주문하기’가 나타난다. 스탬프를 누르면 도장이 찍히듯 색이 채워지고 오른쪽 위에 ‘얍!’ 말풍선이 잠깐 나타난 뒤 다음 단계로 이동한다. 기존 ‘고민 상담’ 스탬프는 변경하지 않는다.
2. 약 1초 동안 두 카드 묶음이 서로 엇갈려 합쳐지는 빠른 셔플을 보여준다. 기존 원형 회전은 사용하지 않는다.
3. 기존처럼 일렬 덱을 훑거나 숫자 키패드로 1장을 고른다. 전체 78장, 정방향만 사용한다.
4. 선택한 카드가 뒤집히고 오늘의 해석이 열린다.

하루 1회 제한은 이번에 적용하지 않는다. 테스트 중에는 반복 이용할 수 있다.

## 결과 화면

- 왼쪽에 카드 이미지와 이름, 오른쪽에 승인된 타르트 캐릭터와 에너지 지수.
- 커스터드 몸만 지수에 맞춰 아래부터 금색으로 채운다. 남은 부분은 연한 회색이며 껍질과 작은 카드는 유지한다.
- 절취선 아래에 핵심 메시지, 오늘의 해석, 하면 좋은 행동, 주의할 행동을 배치한다.
- 따뜻한 한국어 구어체로 구체적으로 작성한다. 낮은 지수를 불행이나 사고의 예고로 표현하지 않는다.
- 작은 보조 문구로 ‘카드의 상징으로 읽는 오늘의 흐름이에요’를 둔다. 지수는 실제 확률이나 측정치가 아니다.
- 최소 너비 280px에서 가로 넘침이 없고, 짧은 화면에서는 해석 영역을 스크롤할 수 있다.

## 구현 방향과 제안 기본값

기존 카드 선택 UI와 Gemini 서버 유틸리티를 재사용하되 오늘의 타로 진입·결과는 별도 경로로 분리한다. 기존 질문 상담 저장, 연계 질문, 시트 차감에 영향을 주지 않는다.

- 해석: 기존 Gemini에 선택 카드와 한국 기준 날짜, 카드 기본 해설을 한 번 보내 구조화된 해석과 0~100 정수 지수를 받는다. 숫자를 포함한 응답 형식을 서버에서 검증한다.
- 서버 응답에는 카드 ID와 해석을 함께 보관해 새로고침 시 같은 결과를 재요청하지 않게 한다. 새로 뽑기는 새 요청이다.
- 요청 중에는 기존 타르트 로딩 화면, 실패 시 기존 오류별 화면을 재사용한다. 실패를 성공한 해석처럼 대체하지 않는다.
- 테스트 단계에는 시트를 차감하지 않고 상담 기록 DB에도 자동 저장하지 않는다. 실제 무료·유료 운영 정책과 하루 제한은 후속 작업이다.
- 새 라이브러리나 DB 테이블은 추가하지 않는다.

대안으로 78장 고정 해설을 작성하면 API 비용을 없앨 수 있지만 별도 콘텐츠 제작이 필요하다. 이번에는 기존 Gemini 연결 재사용을 권장한다.

## 필요한 자산과 최소 확인

승인된 원본은 보존하고, 단일 캐릭터와 몸 채움 마스크만 파생 제작한다. 타입 검사, 지수·응답 검증에 필요한 소수의 테스트, 모바일 너비에서 메뉴→셔플→선택→결과 확인만 수행한다. 관련 없는 테스트나 리팩터링은 하지 않는다.
