# 타로 주제 선택 화면 설계

## 목표

타로 유형을 고른 다음 사용자가 자신의 고민 주제를 하나 선택하도록 한다. 선택한 주제는 카드 섞기와 선택 단계를 거쳐 결과 화면까지 유지하며, 이후 주제별 해석 데이터와 연결할 수 있어야 한다.

전체 사용자 흐름은 다음과 같다.

1. 타로 방식 선택
2. 주제 키워드 선택
3. 카드 섞기
4. 카드 선택
5. 선택한 주제에 맞는 결과 확인

## 주제 구성

화면에는 다음 여덟 가지 고민 영역을 표시한다.

- 상대의 마음
- 새로운 인연
- 관계의 흐름
- 일·커리어
- 금전운
- 인간관계
- 선택·결정
- 나의 흐름

`현재 상황`, `문제의 원인`, `미래 전망`, `조언`은 고민 영역과 성격이 다르므로 주제 카드로 섞지 않는다. 이 항목들은 추후 각 주제의 결과를 구성하는 해석 관점으로 사용한다.

## 화면과 상호작용

- 타로 유형 선택 화면에서 사용 가능한 유형을 누르면 `/topic`으로 이동한다.
- 주제는 모바일 2열 카드 목록으로 배치한다.
- 한 번에 한 주제만 선택할 수 있다.
- 선택한 카드는 금색 테두리, 배경 변화, 체크 표시를 함께 사용해 색상만으로 상태를 구분하지 않도록 한다.
- 다른 카드를 누르면 이전 선택은 해제되고 새 카드만 선택된다.
- 주제를 선택하지 않은 동안에는 하단 이동 버튼을 렌더링하지 않는다.
- 주제를 선택하면 `이 주제로 타로 보기` 버튼이 화면 하단에 부드럽게 나타난다.
- 버튼을 누르면 선택한 주제를 저장하고 `/shuffle`로 이동한다.
- 브라우저 뒤로 가기로 돌아오면 직전에 고른 주제를 다시 표시한다.

## 반응형 디자인

- 최소 280px 너비에서도 2열 구성을 유지한다.
- 좌우 여백, 카드 사이 간격, 글자 크기는 좁은 화면에서 함께 줄어들도록 한다.
- 카드 문구는 짧게 유지하며 줄바꿈 때문에 높이가 불규칙해지지 않도록 동일한 최소 높이를 사용한다.
- 하단 버튼이 목록을 가리지 않도록 선택 상태에서만 충분한 하단 여백을 추가한다.
- 버튼은 안전 영역(`safe-area-inset-bottom`)을 고려한다.

## 상태와 데이터 흐름

- 주제의 식별자와 화면 문구는 하나의 상수 목록에서 관리한다.
- Zustand 주제 선택 스토어에는 선택한 주제 식별자 하나만 저장한다.
- 선택 상태는 기존 앱 상태 관리 방식에 맞춰 세션 저장소에 유지한다.
- 초기화 동작에는 주제 선택 초기화를 포함한다.
- 결과 화면에서는 저장된 식별자로 주제 문구를 조회한다. 이번 작업은 주제 선택과 전달까지만 담당하며 Supabase의 주제별 해석 스키마는 추가하지 않는다.

## 구성 요소 경계

- 주제 페이지: 제목, 설명, 주제 카드 목록, 조건부 하단 버튼을 조합한다.
- 주제 카드: 문구를 표시하고 선택 여부에 따른 시각 상태와 접근성 상태를 담당한다.
- 주제 상수: 식별자와 표시 문구의 단일 기준이다.
- 주제 스토어: 선택, 조회, 초기화만 담당한다.

기존 타로 유형 선택 화면은 목적지 경로만 `/topic`으로 변경한다. 카드 섞기와 카드 선택 애니메이션은 수정하지 않는다.

## 예외 처리

- 저장된 주제 식별자가 현재 목록에 없으면 미선택 상태로 처리한다.
- 직접 `/shuffle`에 접근했을 때 주제가 없으면 `/topic`으로 돌려보내 흐름을 복구한다.
- 타로 유형도 없는 상태에서 `/topic`에 직접 접근하면 타로 유형 선택 화면으로 돌려보낸다.

## 검증

- 주제 상수와 단일 선택 상태의 동작을 확인한다.
- 미선택 상태에서는 이동 버튼이 없고, 선택 후에는 나타나는지 확인한다.
- 다른 주제를 누를 때 선택 표시가 하나만 남는지 확인한다.
- 버튼을 누르면 `/shuffle`로 이동하고 선택 값이 유지되는지 확인한다.
- 280px 모바일 화면에서 카드와 버튼이 겹치거나 잘리지 않는지 브라우저로 확인한다.
- 기존 카드 섞기 및 선택 흐름에 회귀가 없는지 현재 테스트와 타입 검사를 실행한다.

## 제외 범위

- 주제별 타로 해석 문구 작성
- Supabase 테이블 또는 API 스키마 변경
- 복수 주제 선택
- 사용자가 직접 입력하는 기타 주제
- 기존 셔플 애니메이션과 결과 카드 디자인 개편
